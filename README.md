# 🚗 ГАЙКА 116 - Авторазбор и запчасти

https://gayka116.ru/

Система управления сайтом авторазбора с каталогом запчастей, админ-панелью и системой заказов.

## 📖 Описание

**ГАЙКА 116** — это полнофункциональный веб-сайт для компании по продаже автозапчастей с авторазбора. Проект включает в себя:

- Публичная часть с каталогом запчастей
- Административная панель для управления контентом
- Система заказов
- Управление автомобилями, категориями и запчастями

## ✨ Особенности

### Публичная часть
- ✅ Адаптивный дизайн
- ✅ Поиск запчастей по марке, модели и году автомобиля
- ✅ Категории запчастей с визуальными иконками
- ✅ Карточки запчастей с фото, описанием, ценой и статусом
- ✅ Форма заказа с автозаполнением
- ✅ Интеграция с мессенджерами (Telegram, WhatsApp, Avito)
- ✅ Плавная навигация

### Административная панель
- ✅ Авторизация администратора
- ✅ Управление автомобилями (CRUD)
- ✅ Управление категориями (CRUD)
- ✅ Управление запчастями (CRUD)
- ✅ Загрузка множественных изображений
- ✅ Управление заказами (изменение статуса, фильтрация)
- ✅ Дашборд со статистикой
- ✅ Динамические формы с подгрузкой данных

## 🛠️ Технологии

- **Backend:** PHP 8+ (PDO)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **База данных:** MySQL 8.4
- **Архитектура:** REST API для AJAX запросов
